# Microsoft Intune App Packaging Examples

A collection of common applications I've needed to package and deploy through **Microsoft Intune**. I'm sharing the scripts, configurations and deployment notes to make life a little easier for myself and anyone else doing the same work.

These are practical examples rather than one-size-fits-all solutions. Check the individual app README and test each package in your own environment before deploying it.

## Applications

The list below is kept **in alphabetical order** and will grow as more apps are added.

| Application | Description |
| --- | --- |
| [CMTrace](CMTrace/) | Microsoft Configuration Manager log viewer, with installation and removal scripts |
| [DesktopInfo](DesktopInfo/) | Desktop system information display with Full and CutDown configurations |
| [Microsoft 365 Apps](Microsoft%20365%20Apps/) | Microsoft 365 Apps deployment package and supporting scripts |

## Company Portal icons

The [`_Icons`](_Icons/) folder contains images that can be used when publishing apps as **Available** in the Intune Company Portal, so users have a recognisable icon to go with the app.

These icons were collected through quick Google searches and are included for convenience. I don't claim ownership of any third-party logos or artwork. **If you're a rights holder and an image shouldn't be hosted here, please let me know and I'll remove it.** If you reuse an icon, please check that you have permission to do so; finding an image online does not necessarily grant redistribution rights.
